# Pro Lens Studio – releases

Installable builds of **Pro Lens Studio**, a WordPress plugin by ESDRepairLab: natural, professional photo enhancement with camera and lens looks, protected details, verified original backups, review-first batches and cost tracking. English and German.

Each [release](../../releases) has the plugin zip `pro-lens-studio-<version>.zip` and its signature `pro-lens-studio-<version>.zip.rsig`, plus the current OpenAI list prices `prices.json` and their signature `prices.json.rsig`. Sites with Pro Lens Studio installed read the latest release from here, check the signatures and show updates under *Plugins → Updates*; *Settings → Pricing → Sync prices* reads the price list.
